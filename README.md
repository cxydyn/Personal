# Personal Coach PWA

Starter PWA for a personal operating system combining:
- Coaching
- Nutrition
- Finance
- AI Coach

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Deploy to Vercel

Push this repository to GitHub, import it into Vercel, and deploy.
